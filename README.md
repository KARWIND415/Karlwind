# Karlwind
1. Open Max, Show Package Manager and install "FluidCorpusManipulation" 
2. Install Surge_XT (https://surge-synthesizer.github.io)
3. Plug and switch on the Karlax
4. Open Karlwind.maxproj
6. Choose a fingering configuration (Karlsax or Karlinet)
7. Choose an instrument (1 to 7)
8. Turn the audio on and adjust the volume
